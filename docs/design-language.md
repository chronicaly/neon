# Neon design language

Current contract, consolidated 17 November 2026 for 0.5.6. This document contains the latest accepted behavior; the [visual reference](neon-design-reference.html) illustrates it with actual client captures. [Historical revisions](history/README.md) preserve earlier decisions and are not current requirements. New explicit user directions take precedence; update this contract when they change it.

## Window, surfaces and text

- Use 132.25% interface scale independent of Minecraft GUI scale: approximately 582×370 display pixels by default (440×280 logical units), with a 423×278 readable minimum where space permits. Keep every control reachable on smaller displays. Inspect actual pages at default/minimum sizes and GUI scales 1–3.
- Drag the whole window by the header/brand and resize through invisible corners. Keep it reachable after viewport changes. Save menu/HUD-column placement separately from profiles; preserve compact placements and completed density migrations.
- Shared menu/drawer/HUD-column shells have six-display-pixel antialiased corners; buttons/fields have three-pixel corners. Fill and stroke use the same contour. Functional switches, rails and swatches remain rectangular. Attached panes share one surface without internal dividers or stacked alpha.
- Panel surfaces use 84% of saved Background alpha and Colors opacity. Module, Settings and ordinary action buttons use 18% of saved Cards alpha/menu opacity at rest and 28% on hover/selection; tint must not increase alpha. Sidebar rows are clear at rest, with faint hover/selection/focus tint and brighter text/icons, never a boxed selection border.
- Preserve saved Vanilla palette and alpha. Defaults: Background `#07090e`, Cards `#0d1119`, Text `#e3eaf1`, Muted `#83909f`, Structure `#202733`, Accent `#84dce6`, Outline `#73c8d3`, Secondary outline `#9985cc`. Sidebar mixes Background with 17% black. Do not overwrite custom colors or repeat migrations.
- Bundled Inter is default/fallback. Settings → Fonts lists installed families with search/live preview, applying the selected family to menus, Client-mode HUD text and Better chat's Client font. Persist selection in profiles and Undo. Missing families fall back without replacing the saved name. Minecraft/resource-pack HUD text stays an independent General choice.
- Native-resolution typography: 16px body, 15px secondary, 19px headings. Shape complete kerned runs, rasterize at 4× and area-resolve once; align origins to display pixels. Preserve smooth alpha, safe fitting, measured caret/selection positions, native editing and IME state. Bound text/atlas caches and invalidate recorded presentations after font changes.
- Keep one thin native-pixel cyan/violet shell outline with a traveling highlight and localized eight-pixel bloom, never a full-perimeter halo. Advance its physical edge distance at 160 display pixels/second; expansion/reversal must preserve its tangential edge position without rebasing around a changing center. Use one ordered mesh with continuous corners. HUD column and attached color drawer use this same animated contour.
- Module/Settings hover lifts painted content two physical pixels inside fixed hitboxes. Use visible cyan-to-violet Gaussian bloom, a brighter border and matching tint over 220 ms. Rounded cutouts must match the surface without dark corner dots. Reserve twelve logical units horizontally and fourteen above the grid to contain falloff. Other active-control glow stays restrained.

## Navigation and search

- Keep Combat, Visuals and Settings as the three categories. Combat/Visuals sit at the sidebar top; Settings/HUD editor sit at the bottom with the same left-aligned icon/text columns. HUD editor opens the canvas directly from every category and returns to the prior category, drawer and both scroll positions. No Overview, Visuals footer, X/Undo/Done button, general footer, decorative copy or bind list.
- Modules use compact equal-width outlined buttons in a spaced wrapping grid. Left click toggles; right click opens a smooth right-hand settings drawer while retaining the grid. Enter/Space toggles; Shift+F10 configures. Retain compact enabled indicators and cyan rectangular boolean switches inside settings. No Advanced folds or duplicate Enabled/Activation controls.
- Bracketed binds sit only at the module button's right edge. Left click assigns; right click cycles Toggle, Hold, Reverse hold. Hover replaces the key with the full mode inside the same brackets and restores it on leave. No floating tooltip, persistent abbreviations or drawer bind controls. Keep fixed hitboxes and single-line labels; fit names only when longer hover modes need room.
- Settings contains Colors, Appearance, Fonts and Profiles in the same grid/drawer model. Either mouse button opens a section, without module toggles/binds/disclosure marks. Module/Settings buttons never use +/−; HUD roots and color rows do.
- Preserve the saved primary menu binding (Insert in Vanilla; P for a fresh config) and separate Right Shift alternate. Either opens/closes. Capture and focused text input take priority; discard shortcuts pressed in chat instead of replaying them later. Preserve saved module keys and activation preferences.
- Search is hidden by default, with no reserved row or hidden focus target. Ctrl+F reveals a compact field that filters current-category modules or Settings sections. HUD search filters column entries, including disabled widgets and General. Match case-insensitive words independent of order. Filtering never changes enabled states, settings, profiles or Undo.
- Ctrl+F reveals/focuses/selects search unless another edit/capture owns input. Enter/Down focuses the first result without activating it. Escape in the search field or its results clears a nonempty query, then hides empty search and reclaims its row before ordinary back navigation. Focused text keys/menu shortcuts do not activate features. Empty results have a short inline label. Clearing restores pre-search scrolling.
- Queries live only in the open screen, retained with search visibility per category across its drawer/category rebuilds and menu-to-HUD round trip; a newly opened HUD editor/menu starts with empty queries. Canvas selection reveals its smooth widget fold and clears a filter hiding it. Dragging never opens a fold or clears search. Disabled widgets remain searchable without becoming canvas targets.
- Process-local navigation remembers category, expanded section per category and per-section scroll across menu reopening. Popups, capture and unfinished drafts stay closed; a fresh Minecraft process starts on collapsed Visuals.

## Motion and input contract

- Mouse/keyboard press feedback settles the two-pixel hover lift and tightens glow over 50 ms, releasing over 100 ms. Hitboxes never move. Bind feedback belongs to its bracket target. Stable identities retain feedback through rebuilds; outside release, focus loss and removal clear held input. Pressing itself adds no sound.
- Use analytic critically damped motion preserving position and velocity on retargeting. Settling targets: ordinary feedback 100 ms, opening/scrolling 120 ms, HUD folds 150 ms, hover/chat lift 220 ms, attached drawers 340 ms. Settings/input apply immediately; camera/FPS smoothing remains separate.
- Content replacement crossfades for 120 ms inside the stable shell. Incoming controls respond immediately; outgoing content is drawing commands only. Closing releases gameplay immediately with an 80 ms render-only fade. Reopening, resize, resource reload and unrelated screens invalidate stale presentations. After search handling, Escape retains edit/gesture, color, settings drawer, menu order.
- Never show scrollbars or scrollbar hitboxes. Wheel motion is smooth/bounded with content-only twelve-unit edge fades; keyboard focus reveals immediately. Preserve clicked fold headers and first visible controls where bounds permit.
- Use native cursor requests for draggable headers/widgets, invisible corners, slider tracks and text entry, retaining the cursor through a gesture. Use native movement fallback for unavailable resize cursors. Hitboxes/clipping determine behavior; normal Minecraft cursors resume outside Neon.
- Numeric controls remain inline only with at least 90 logical units of actual track; otherwise use a 44-unit row with a full-width rail below label/value. Keep eight-unit solid accent rails without thumbs/end markers. Paint fill eases over 120 ms; settings/readouts are immediate. No Reset.
- Ordinary dragging maps directly to the actual track, clamps outside and realigns on re-entry. Preserve an unrounded accumulator. Once Shift precision is used, keep relative dragging until release so modifiers never jump; sensitivity is one-tenth. Left/Right moves one increment, Shift+Left/Right ten. Exact fractions are not rounded by opening controls. Enter commits, Escape cancels, valid outside clicks commit and invalid drafts remain marked.
- Gestures own movement/release and suspend wheel scrolling. Outside release finishes; focus loss retains applied values; Escape cancels numeric/placement gestures as one Undo step. Window/HUD/color movement stays pointer-attached. Preserve focused drafts, keyboard access, narration and Undo across rebuild/resize.
- Copy and profile Save/Update show Copied/Saved for 900 ms, then fade back over 120 ms inside unchanged buttons. Acknowledge only successful writes/completed persistence; discard obsolete async results.

## Colors, appearance and audio

- Colors owns Theme, Rainbow (Cycle/Saturation/Brightness), Background, Outline, Accent, Text, Cards, Secondary outline, Muted text and Opacity (40–100%, default 94%). Keep Unity's RGB-triggered linking, independent alpha and per-color Sync. RGB edits detach one role; Sync restores following. Preserve the saved palette until Theme changes/Rainbow is enabled. No named preset catalog or Reset.
- Color rows open one attached right-hand drawer with reversible module-drawer motion, shared surface/outline. Width is 168 logical units; use a full-width HSV square (about 190 display pixels high at default size), closely stacked hue/opacity strips, tiny original/current chips beside hex, and compact Copy/Paste/Sync. Match native headings/light-glass actions. Shrink the square at minimum height to retain every action.
- Apply colors live; Escape/outside click closes only the color drawer and keeps applied values. The dismissing click is consumed. Clicking another visible color row switches directly. Closing controls stop receiving input immediately. Narrow displays temporarily replace the settings pane and restore its scroll/input targets on dismissal. The shared header moves the whole menu/column. No independent floating picker or Apply/Cancel.
- Keep Unity parsing for hex, RGB(A), HSB and named colors. Each drag/completed hex edit is one Undo gesture. Invalid paste displays Invalid in the existing button, with formats explained on hover/focus/narration; color/Undo remain unchanged and silent. Valid paste/edit clears the error. Persist links, overrides, alpha and rainbow in profiles.
- Appearance directly owns UI sounds (0–100%, default 40%) and Effects (Adaptive/Full, default Adaptive). Only backdrop blur/decorative control glow may adapt. Native text, perimeter, HUD items and gameplay blur remain full quality. Never change Minecraft's saved blur preference.
- Use original soft console-style electronic cues with rounded tones, gentle transitions/releases and no sharp attacks/noise swishes. Neon audio runs asynchronously, independently of Minecraft volume, with brief worker-side fades for interrupted voices. Hover is 35% of action gain, with 80 ms cooldown and 100 ms suppression after actions.
- One semantic cue per accepted input: hover/focus, navigation/back, confirmation, enable/disable. Scrolling, dragging, resizing, typing, continuous color/numeric edits and unchanged/rejected actions stay silent. Never use vanilla menu clicks. Verification intercepts Minecraft/Neon playback while retaining sound assertions; disable optional voice chat in isolated test clients.

## HUD editing and rendering

- Retain all 24 existing HUD elements, including Chat, in Unity-derived expandable rows and a compact draggable 188-unit column. Newly introduced widgets start disabled. No intermediate cards, coordinate forms, presets, full-width toolbar or bottom hints. Keep the world sharp/undimmed.
- Root rows use inset light-glass controls, compact enabled indicators and +/− disclosure. Children use cyan booleans and right-aligned choices/numbers. Left click toggles roots; right click expands. Numeric rows support whole-row dragging and right-click/Enter exact entry with correct track mapping. Folds animate clipped height/column size, and immediately disable closing controls.
- Render/hit-test only enabled canvas widgets, including previews. No selection outlines, visible resize handles or floating labels. Drag, invisible-corner resize, wheel-scale where supported, and arrow-nudge one physical pixel (Shift: ten). Cursor, left click and right click give the selected enabled widget priority wherever canvas targets overlap. Click reveals settings, ignoring up to three pixels jitter; real gestures hide the column until release and never open folds. Tab/H hides controls unless text entry owns input. Retain gesture Undo/cancellation and optional guides.
- Enabled edges catch at six physical pixels and align perpendicular edges/centers. Edge resistance works with General Snap off; Snap adds general alignment. Hold until breakaway, then allow deliberate overlap; fast crossings catch once and existing overlaps remain movable. Alt bypasses snapping. Hidden widgets never attract.
- General exposes HUD scale (0.5–2×), Guides, Snap, Snap sensitivity (1–24 display pixels), Client/Minecraft font, HUD surfaces master, Backgrounds, Outlines, Equipment panels and Animated outline. Masters preserve local preferences. Profiles include settings/placements but not column/window position.
- Center HUD text by visible ink, with one baseline for colored runs. FPS has a stationary label, right-aligned four-digit field and stable digit baseline. Client text defaults to Inter. Minecraft mode respects resource packs, quantizing glyph sizes/origins to physical pixels while preserving precise saved scale. Preserve native items/decorations, scoreboard styles and shadow ordering.
- Information panels use tight rounded glass surfaces (four horizontal/two vertical pixels padding at default scale), local Background/Border/Shadow and honest live data. Poll gameplay information per tick, clocks at their own cadence. Editor samples never alter real data. Physical CPS excludes synthetic/menu clicks.
- Nearby enabled panels merge across six-pixel spacing into one translucent fill/outer contour, retaining holes and deliberate overlaps without stacked opacity/internal borders. Flatten rounded contours before union, never stroked-curve boolean operations. Bound caches and key meshes relative to origin so translation reuses tessellation. Use one framebuffer-space cyan/violet outline field; retain FPS local colors.
- Armor stays fixed beneath chat. New/reset armor is bottom-aligned left of offhand/hotbar; preserve existing placements. Armor/floating widget size follows Neon scale independently of Minecraft GUI scale. Keep orientation, order, frames, spacing, warnings/threshold and copied-item damage preview; equipment panels retain native models.
- Attached totems follow the real offhand slot, ignoring HUD/wheel scaling. Dragging or choosing Floating detaches; Undo restores the complete change. Show Scale only while floating and preserve native count/item semantics.
- FPS exposes Scale, Smooth FPS, Background, Border, Shadow and separate Label color, Value color, Background color, Border color directly in its fold. Defaults follow theme roles; edits affect only FPS and Sync restores that role's link. Persist overrides with settings/profiles/Undo. Defaults: enabled bottom-right, smoothing/background/border off, shadow on. Optional easing affects the number only; HUD text never inherits menu opacity/fades.
- Coordinates has compact comma-separated values and optional inline Nether conversion, no dimension text/toggle. Potion effects → Hide vanilla icons suppresses top-right native icons only while that HUD is enabled. Clean view has an independent Hide effect icons switch. Both default off, preserve actual effects and support profiles/Undo.

## Chat and established modules

- Better chat remains in Visuals, adapting Unity duplicate counts, entry animation, whole-name highlighting, proportional font/click layout and input styling. Preserve original messages, signatures, trust tags/warning details, links, source filtering, fading and scroll anchors. Font/width/filter/settings reflows never ping. Cache unchanged display groups/layouts within native history/cache bounds.
- Emit one message or mention ping only on accepted new player/server chat, independently of UI/Minecraft volume. A mention uses one distinct two-note cue. Reflow, local notices, action bars and history redraw remain silent. Keep direct Message ping, Mention ping, Ping volume, Duplicates, Animation, Duration, Highlight name, Mention color, Client font, Input frame and Message bar controls.
- Optional Chat HUD starts disabled, using native history and shared drawing/click transforms with ordinary scale/background/border/shadow. Never insert preview messages. Hide the chat scrollbar while enhancements are active; preserve native wheel/keyboard scrolling, editing and suggestions.
- Chat → Message bar shares Better chat's preference and works independently of Better chat/custom placement. Hiding removes only the stripe and four-unit gutter from drawing and hit testing. Custom panels retain two native units of ordinary padding; preserve trust metadata and warning affordances.
- Enabled Chat/Coordinates at normalized x ≤ 0.1 and y ≥ 0.8 form a bottom-left stack with six physical pixels separation. Use one cached displacement per frame and velocity-preserving 220 ms motion around the real input widget. Remove unused queue gutter; shorten at small-display tops and cap native visible lines. Preserve scrolling/click collection and saved coordinates. Moving either away restores ordinary behavior.
- Other bottom HUD groups overlapping chat input lift together with four-pixel clearance and preserved relative spacing. Use render-only offsets; editor previews keep saved geometry. Armor/attached totems stay fixed. Joined outlines track the lift.
- Freelook directly exposes Distance (1–16 blocks, default 4), bind only in the header. Motion blur defaults to 10%, preserving custom strengths. Zoom keeps Magnification, Transition, Scroll zoom. Autoclicker retains useful click controls, Entities only, separate Left action Click/Hold and its established persistent Toggle semantics.
- Screenshot is the compact button; drawer/narration says Better screenshot. Default disabled, optional header bind and direct Notify; copy ordinary screenshots without changing PNG saving, with silent local notices.
- Preserve the existing expansion: centered fractional crosshair coverage, Unity-derived Block outline silhouette modes, final-native-quad Low fire mapping, all feature eligibility and cosmetic behavior. Search/performance work must not change those semantics.

## Verification and delivery

Target Minecraft 26.2, Java 25 and unobfuscated Fabric Loom. Run an actual Gradle build after every completed code/configuration set. Verify the packaged runnable JAR. Keep profiling, clipboard/audio interception in the separate verification mod. Inspect real module/Settings/HUD/color pages at default/minimum sizes, including last scrolled rows. Report allocations/frame times with limitations; never promise an FPS increase from allocation reductions.

Install only the successfully checked exact runnable JAR into PrismLauncher Vanilla. Never install stale output after failure. Keep existing Minecraft instances open and preserve Unity's separate checkout/artifacts. State unavailable native-key, mixed-DPI and endurance coverage honestly.
