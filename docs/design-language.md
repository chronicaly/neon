# Neon design language

## Premium interaction contract

Scroll edges softly dissolve the final twelve logical units of a partially visible row. Fully visible controls keep their normal alpha. This is content-only feedback: no scrollbar, overlay surface, new input target, or change to wheel motion and immediate keyboard focus reveal.

Rejected color paste displays Invalid inside the existing Paste button without changing its size or semantic action. Hover/focus and narration explain that no valid color was found and list the accepted Unity formats. Keep the current color, Undo history and sound silence; a valid paste or color edit clears the error.

Module, Settings and ordinary action buttons share immediate mouse/keyboard press feedback. Pressing settles the two-pixel hover lift and tightens its glow over 50 ms; release takes 100 ms. Hitboxes never move. Bind feedback belongs to the bracketed target. Stable control identities retain feedback across rebuilds; outside release, focus loss and removal clear held input. Pressing adds no sound.

UI motion uses an analytic critically damped response that preserves position and velocity when retargeted. Existing hover, drawer, HUD-fold and slider-fill durations remain settling targets. Input, settings and exact keyboard focus reveal stay immediate; camera and FPS smoothing are separate. Preserve the outline highlight's physical edge position during every reversal.

Category and settings-content replacement crossfade for 120 ms inside the stable shell. Incoming controls respond immediately; outgoing content is drawing commands only. Rapid changes replace the pending transition. Closing releases the screen immediately and fades only its recorded presentation over 80 ms while gameplay continues. Reopening, viewport changes, resource reload and unrelated screens invalidate stale presentations. Escape retains its editing/gesture, color, drawer, menu order.

Use Minecraft's native cursor requests: movement on draggable headers and enabled HUD widgets, diagonal resize on usable invisible corners (native movement fallback), horizontal adjustment on slider tracks, and text cursors for exact entry. Use input hitboxes and clipping, retain the gesture cursor until release, and let normal Minecraft behavior resume outside Neon.

Copy and profile Save/Update show Copied/Saved inside their existing buttons for 900 ms, followed by a 120 ms return fade. Geometry and semantic labels stay stable. Confirm only successful clipboard writes or completed profile persistence; ignore obsolete asynchronous results after navigation or newer operations. Accepted operations keep their existing single confirmation cue. No new configuration or settings are introduced.

Its compact button reads Screenshot to preserve the existing two-column grid; the settings drawer and binding narration use Better screenshot. Keep its optional activation bind in the bracketed header target and expose only Notify in the shared drawer. It starts disabled, copies normal screenshots without changing vanilla PNG saving, and posts silent local notices. Settings, profiles and binding Undo follow the shared module controls.

Each defaults to its existing theme role, preserving saved Vanilla colors and alpha; editing creates only that FPS override, and Sync restores theme following for that color. Use the shared compact picker in a reversible attached drawer inside the HUD column's quiet static border. Keep the world sharp, all live widget placement behavior, per-gesture Undo and profile persistence. The FPS color editor never changes the menu theme. Its header moves the whole HUD column and drawer; fit it within the display and keep the applied colors when dismissed.

Closing controls stop receiving input immediately while their contents animate out.

Better chat belongs in Visuals with the existing module controls. Adapt Unity's consecutive duplicate counts, entry animation and whole-name highlighting while preserving vanilla chat rendering and signed history. The latest 12 November module layout supersedes the earlier option B module rows: compact, equally wide outlined buttons in a spaced wrapping grid. Left click toggles the module; right click opens its settings to the right while keeping the grid visible. The bracketed bind is right-aligned inside its module button. Left click the bind to assign it; right click cycles Toggle, Hold, Reverse hold. Hovering the bracketed bind replaces the key with the full current mode inside the same brackets: [Hold], [Toggle], or [Reverse hold]. Restore the key on pointer leave. No floating mode tooltip or persistent T/H/RH indicators. Keep the button geometry fixed; fit the name with an ellipsis only if the hovered mode needs extra space. Module and Settings grid buttons have no +/− marks. Activation mode controls never appear in the drawer. Use the user-approved cyan rectangular switch for boolean settings inside modules; module buttons retain their compact enabled indicator. Motion blur and Totem pops have real optional bindings, unbound by default. Existing keys, activation preferences and custom values survive loading. Colors, Appearance and Profiles now use the same outlined button grid and right-hand drawer. Either mouse button opens/closes a Settings section; these buttons have no module toggle or bind. The HUD editor retains its existing expansion model.

The drawer opens over 340 ms with reversible easing. Do not draw an internal vertical divider between the module grid and settings drawer; both panes share one continuous surface. The same interpolated rectangle drives the surface, clipping and ONE native-pixel outline. The traveling highlight uses physical perimeter distance at 160 display pixels/second, preserves its tangential edge position when geometry changes, and retains a fixed bloom footprint. Expanding or reversing must never reposition the glow by recomputing its angle around a changing center. If its edge itself moves, only that edge's normal motion carries it. The latest hover correction uses a broad, clearly purple Gaussian bloom around module and Settings buttons, with a cool cyan shoulder on the left, a saturated violet right edge and a matching violet surface tint. Enhance the secondary color for this hover effect without changing saved theme values. Its twelve-unit falloff uses continuous color interpolation, with no stacked frame halos. The two-display-pixel lift and glow ease together over 220 ms and reverse from the current amount. Reserve twelve units of horizontal and fourteen units of top grid padding so the bloom is not clipped at the first/last button. Module buttons, Settings tiles and ordinary actions use one light-glass surface: 18% of the saved Cards alpha/menu opacity at rest, interpolating to 28% on hover or selection. Color tinting must not increase that alpha. Sidebar rows have no idle fill and a faint 28% panel-alpha hover/selected tint. Text and outlines remain readable; slider fills, switch indicators and swatches keep their functional colors. Other controls and the traveling window outline keep their existing glow. All button widths are measured together, including the right-aligned bind and its padding; names and binds remain single-line at supported default/minimum sizes.

The latest slider correction widens the shared settings drawer to 300 logical units (about 397 display pixels), constrained by the display while preserving the module pane. Keep numeric controls inline only when the actual bar has at least 90 logical units of width. Otherwise use a 44-unit row with label and value together above a full-width bar; the value's exact-edit target stays in the text line. This supersedes the earlier preference for single-line sliders at every width. Keep the solid accent fill, dark rail, eight-unit height, and no thumb, inset or end indicator. Ease only the painted fill over 120 ms; settings and readouts apply immediately. Ordinary dragging maps directly to the pointer along the actual track, clamps outside either end, and realigns immediately on re-entry. Preserve the unrounded position for precision: once Shift is used, keep relative dragging until release so modifier changes never jump; the next ordinary press starts direct positioning again. Retain cancellation, Undo, silent continuous input and motion across rebuilds. HUD numeric rows keep their translucent full-row styling and share the corrected drag behavior.

The latest 12 November sound direction is smooth, soft electronic beeps with an Xbox/PS5-inspired feel that fits Neon. Use rounded sine tones, restrained octave warmth, gentle screen transitions and soft releases. Avoid percussive knocks, noise swishes, sharp attacks and wide pitch sweeps. Keep hover short and quieter than actions, preserve saved UI volume, and fade interrupted voices briefly on the audio worker. Sounds are original synthesis.

Color dismissal continues to keep live edits. Window, HUD, and picker movement stay directly attached to the pointer.

Popups, bind capture, and unfinished drafts do not reopen. A fresh Minecraft process starts on collapsed Visuals. Configuration and profile formats remain unchanged.
